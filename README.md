# Эмулятор UNIX-подобной оболочки

Вариант 31.

Программа имитирует работу командной строки UNIX-подобной операционной системы. Виртуальная файловая система хранится в CSV-файле и загружается в память при запуске программы.

## Возможности

Программа поддерживает следующие команды:

- `ls` — вывод содержимого текущей директории;
- `cd` — переход в указанную директорию;
- `whoami` — вывод имени текущего пользователя;
- `echo` — вывод переданных аргументов;
- `who` — вывод имени пользователя;
- `chown` — изменение владельца объекта виртуальной файловой системы;
- `cp` — копирование файла;
- `vfs-load` — загрузка другой виртуальной файловой системы из CSV-файла;
- `exit` — завершение работы программы.

Также поддерживаются:

- аргументы в кавычках;
- относительные и абсолютные пути;
- переходы с использованием `..`;
- обработка ошибок команд;
- выполнение команд из стартового скрипта;
- хранение бинарного содержимого файлов в формате Base64.

## Структура проекта

- `src/main.py` — основной программный код;
- `tests/test_parser.py` — тесты разбора команд;
- `vfs/` — CSV-файлы виртуальных файловых систем;
- `scripts/` — стартовые скрипты и сценарии проверки команд;
- `run.sh` — запуск программы в интерактивном режиме;
- `README.md` — описание проекта.

## Основные функции программы

- `parse_arguments()` — обработка параметров командной строки;
- `load_vfs()` — загрузка виртуальной файловой системы из CSV;
- `valid_csv_row()` — проверка корректности строки CSV;
- `parse_command()` — разбор введённой команды и её аргументов;
- `decode_content()` — декодирование содержимого в формате Base64;
- `normalize_path()` — нормализация пути;
- `list_directory()` — получение содержимого текущей директории;
- `change_directory()` — переход между директориями;
- `change_owner()` — изменение владельца объекта;
- `copy_file()` — копирование файла;
- `execute_command()` — обработка и выполнение команд;
- `run_script()` — выполнение команд из стартового скрипта;
- `run_interactive()` — работа в интерактивном режиме;
- `main()` — точка входа в программу.

## Параметры запуска

Программа принимает следующие параметры командной строки:

- `--vfs` — путь к CSV-файлу виртуальной файловой системы;
- `--script` — необязательный путь к стартовому скрипту.

## Запуск

Сборка проекта не требуется.

Для запуска в интерактивном режиме используется команда `./run.sh`.

Для запуска готового сценария проверки команд используется `./scripts/start.sh`.

Для проверки минимальной виртуальной файловой системы используется `./scripts/run_minimal.sh`.

Для проверки обработки некорректного CSV-файла используется `./scripts/run_broken.sh`.

## Тестирование

Для запуска автоматических тестов используется команда `python3 -m pytest`.

Для проверки синтаксиса Python-файлов используется команда `python3 -m py_compile src/main.py tests/test_parser.py`.

## Примеры использования

После запуска программы можно выполнять команды:

`ls`

`cd documents`

`ls`

`whoami`

`echo Hello`

`who`

`exit`

Пример запуска с указанием VFS и стартового скрипта:

`python3 src/main.py --vfs ./vfs/files.csv --script ./scripts/commands5.txt`

Виртуальная файловая система загружается из CSV-файла. Формат файла:

`path,type,content`

`/,directory,`

`/hello.txt,file,Hello VFS!`

`/documents,directory,`

Для файлов с бинарным содержимым используется представление Base64.

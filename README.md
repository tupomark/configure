# Конфигурационное управление

Практические работы, вариант 31.

| Работа | Описание |
| --- | --- |
| [Практическая работа №1](practice1/README.md) | Эмулятор UNIX-подобной оболочки |
| [Практическая работа №2](practice2/README.md) | Граф зависимостей NuGet |

Каждая работа хранится в своей папке с исходным кодом, тестами и скриптом запуска.

## Запуск из корня репозитория

Первая практика:

```sh
./practice1/run.sh
```

Вторая практика - демонстрация тестового графа без доступа к сети:

```sh
cd practice2
sh run.sh --package A --version 1 --test-repo \
  --repository examples/cycle.json --stage 3
```

Подробные команды запуска и тестирования находятся в README каждой работы.
